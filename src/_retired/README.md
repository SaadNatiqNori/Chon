Screens and data from the fuller version of Chon: the platform library with
filters, the four-question wizard, the saved checklist, the Safety & 2FA page,
the fullscreen step viewer, and the drawn phone screens that stood in before
real screenshots existed.

Nothing here is imported. It is kept only so the work can be pulled back in if
any of it is wanted again — `source.js` in particular still holds the guide text
for Telegram, Google, Instagram, Facebook and Apple, which is worth reusing when
those platforms get photographed.
